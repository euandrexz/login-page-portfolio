# Página de Login Responsiva

Projeto simples de uma página de login feita com:

- HTML5
- CSS3
- JavaScript puro

## Objetivo
Demonstrar habilidades de estruturação de interface, responsividade, estilização moderna e validação básica de formulário.

## Funcionalidades
- Validação de email
- Validação de senha
- Mostrar/ocultar senha
- Layout responsivo
- Interface moderna para portfólio

## Como visualizar
Basta abrir o arquivo `index.html` no navegador.
